H

Designed for accessibility.

Other accessibility apps describe your screen. Handy AI does the task. Tell it what you want — send a message, order food, set a reminder — and it executes across any app on your phone. The Accessibility API was built for this; we're using it the way it was meant to be used.

Voice-first, end to end

Speak the task. Hear the agent's plan, every action it takes, and the result. Optional verbosity from brief to detailed. Default ON when TalkBack is detected.

TalkBack-compatible

The app's own UI works with TalkBack — every button has a proper label and the chat is announced as it arrives. Verified on Pixel.

Voice-confirm destructive actions

Before tapping Send, Buy, Delete, or other destructive buttons, Handy AI speaks a warning so you can hit Stop if the agent got it wrong.

Easy Mode

One giant mic button. No chat history, no menus, no settings to navigate. Designed for users with cognitive load, motor disabilities, or who simply want the simplest interface possible.

Set up by computer

Don't paste a 100-character API key on the phone. Get a 6-character code, enter it on your laptop at gethandyai.app/setup, paste your key with your desktop screen reader, and the phone receives it.

Bluetooth headsets + hearing aids

Audio routes through whatever output your phone uses — including Bluetooth headsets, hearing aids, and the spoken-feedback channel TalkBack already configured for you.

Describe it. Handy does it.

No macros, no workflows you have to build. Handy AI looks at your screen, one step at a time, decides the next tap, and keeps going until the task is done.

Voice or text

Tap the mic and say it. Or type. "Message Sarah on WhatsApp that I'm running late."

Sees what you see

Handy takes a screenshot, figures out the next tap, and executes. Then takes another. Until it's done.

Stops when you say

Big Stop button flips the agent off instantly. Won't enter passwords or run destructive actions unless you explicitly ask.

Install Handy AI

Get it on Google Play

Set up Claude

If your version offers included Claude, review the screen-sharing prompt before opting in. You can also use your own Anthropic API key. If you use a desktop screen reader, you can set up your key from a computer.

Ask Handy AI to read your screen

Say or type “Read the text on this screen.” If prompted, turn on Handy AI in Android’s Accessibility settings, then return to the app. Try it on a screen you’re comfortable sharing.

You can also download the signed APK. Android may ask you to allow installs from your browser.

Watch how to start a screen read

The video shows the example button from the 1.5.8 website APK. You can also say or type “Read the text on this screen.”

Read the setup steps
  1. Finish Claude setup. Open Accessibility settings from the chat, turn on Handy AI and return to the app.
  2. Choose Use screen-reading example to fill the editable prompt.
  3. Review the prompt. On a screen you’re comfortable sharing, tap Start, the round button on the right.

Accessibility says “Restricted setting”

On Android 13 and up, this can appear after an APK install. Google Play is the recommended install route when available.

If you installed the official signed Handy AI APK and trust the app, open Settings → Apps and select Handy AI. Look under See all apps or App info if needed.

Tap More → Allow restricted settings and follow Android’s prompts. Then enable Handy AI under Settings → Accessibility. On some phones, open Installed apps to find it. Return to Handy AI to try your first task.

Accessibility lets Handy AI read screen content and interact with apps on your behalf. Read Android’s guidance on restricted settings.

Short answers.

Is it safe to install?

Yes — the APK is signed with our release key. You can also install it from Google Play. Source is open at github.com/fainir/handy-ai.

What phones does it work on?

Android 11 and up. The Accessibility screenshot API requires API level 30+.

What does it cost?

The app is free to install. With your own Anthropic key, Anthropic bills you directly for API usage. Builds that offer included Claude let you try up to 10 model steps first.

Can it enter passwords or run payments?

The system prompt tells it not to, unless you explicitly ask. That's guidance to the model, not a hard sandbox — treat it accordingly.

Where does my screen content go?

During a task, your phone sends screen context to Anthropic. If you enable included Claude in a build that offers it, the request goes through the Betterloop gateway. See the privacy policy.
