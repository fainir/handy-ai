Privacy policy

Last updated: 9 November 2026

Handy AI helps you carry out tasks on your Android phone by describing them in plain language. This page explains what data it handles and how.

What the app stores on your device

  • Your Anthropic API key. The app stores it encrypted with Android Keystore and uses it only to authenticate direct requests to Anthropic. If you choose setup by computer, Dashob relays the key to your phone with a short-lived setup code. You can also enter it directly on your phone.
  • Chat history. The app saves your tasks and action log in app-private storage. A running task sends the context it needs as described below.
  • Task descriptions and recent screenshots, only while a task is running. Kept in memory, not written to disk.

What leaves your device

  • With your own key. The phone sends task text, screenshots and action history directly to Anthropic while a task is running.
  • With included Claude, in versions that offer it. After you agree in the app, Handy AI sends the current screenshot, task and recent actions through the Betterloop gateway to Anthropic. The gateway does not retain the request contents. It keeps pseudonymous profile and network digests, request IDs, timestamps and usage to enforce limits. The response is encrypted and available for recovery for up to one hour. Turn off included Claude in Settings to stop future requests in this mode.
  • Keep passwords, payment information and other sensitive details off screen while a task runs. Anthropic privacy policy and API retention policy

What we do NOT collect

  • Contacts, SMS, calls, microphone (except during the brief voice-to-text call handled by Android itself), camera, location — no access, no collection.
  • The included trial does not build advertising profiles. Some builds use Sentry for crash reports if configured. Screenshot and key entry are separate from crash reporting.
  • Using included Claude or adding an Anthropic key does not require a Handy AI account. Optional sign-in and device pairing are separate features.

Accessibility permission

Handy AI uses Android's Accessibility Service API strictly to: (a) take a screenshot of the current screen while a task is running, and (b) dispatch taps, swipes, and text input on your behalf. The service only does work while you have a task running. You can turn it off any time in Settings → Accessibility → Handy AI.

Deleting your data

  • Tap "Clear API key" in the app Settings to wipe your key immediately.
  • Use the sessions drawer "⋮" menu to delete individual chats.
  • Uninstalling the app (or clearing app data from Android Settings → Apps → Handy AI) removes all on-device data.

Security

All secrets on-device are encrypted via the Android Keystore. All network traffic is HTTPS (TLS 1.2+).

Children

Not intended for children under 13. We do not knowingly collect data from children.

Optional website analytics

If you allow analytics in the homepage footer, enabled providers may receive a homepage visit or a click on a Google Play or APK install button. Google Analytics and Mixpanel receive those events. Betterloop also measures interactions, loading performance and website errors, with text capture disabled. This can use a random browser or session identifier. The website excludes setup and legal pages from analytics. The site does not send key setup codes, API keys, screen images or task content to analytics providers.

Analytics is off by default. Use Analytics choices on the homepage to turn it off again. The website also respects Global Privacy Control and Do Not Track.
