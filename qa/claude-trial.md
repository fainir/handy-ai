# Handy AI 1.5.7 trial acceptance

The included path uses the existing Betterloop Claude credential through the guarded gateway. The APK contains a gateway URL. The personal key is saved through Android Keystore and goes to Anthropic when the user chooses the personal-key path.

- [Gateway PR](https://github.com/fainir/betterloop/pull/33) passed local typecheck, build, 332 PostgreSQL checks and the multi-process quota test. The new tests reject an invalid image before reservation, refuse the eleventh step across billing windows and networks, and keep an unauthenticated provider error from pausing the shared gateway.
- November 9, 2026, Railway deployment `96c7a280-255a-4c30-bf8d-847b8f075fad` was the only active Betterloop web deployment and reported `SUCCESS`. The public health check returned 200. An SSH readback found the 19 existing profiles and the new `handyai:assist` profile. The shared budget control still had its existing limits and expiry.
- One public HTTPS request with a synthetic white JPEG returned 200 from Claude Haiku 5.5 and nine trial steps remaining. A read-only query found the same request completed as `handyai:assist`, with 1,582 input tokens, 55 output tokens and a booked cost of $0.000186. No personal screen or text was used.
- Android local CI on the final app source completed debug and release builds, lint, 38 JVM tests, a signed APK and a signed bundle. The tests exercise the native request, response and Stop behavior over loopback HTTP and coordinate conversion from the resized screenshot. They do not dispatch a real Claude request.
- The package identifies as `com.claudeagent.phone` version `1.5.7` (code `17`), minimum API 30 and target API 36. APK and AAB signers match the existing direct APK. Signature checks, APK 16 KiB alignment and 16 native ELF load-segment checks passed. The APK DEX scan found no embedded Anthropic key. AAB SHA-256 `1271ce6bde62b9604f856a10f971a6fc072188bee2b984bf6e49106c3598f736`.
- Android 16 upgraded the previous signed 1.5.5 APK in place. [The screen-sharing prompt](android-trial-consent.png) keeps the trial off when dismissed. Consent unlocked the task composer without a personal key.
- Opening the keyboard originally squeezed out the composer. The activity now consumes the insets after reserving space. Android 16 at 320×640 and [375×812](android-trial-composer.png) kept the composer and Start control visible above the open keyboard. Settings saved and masked a dummy personal key, turned off the trial, and removed the key without sending it to Anthropic.
- A live tool continuation exposed a short-history aliasing bug. The final signed APK retains the initial task and tool messages when replacing the trimmed history. On Android 16, the signed app used `read_screen_text` once and successfully called `finish` on the next model step with the correct title, “Handy AI”. [Completed task](android-trial-complete.png).
- Chromium rendered the staged homepage, privacy policy and terms at 375px and 1440px. All three had matching trial copy and no horizontal overflow. [Mobile privacy screenshot](privacy-375.png).
